# Agent CLI 实施计划

> 执行技能：subagent-driven-development；已获用户实施授权，持续完成无需重复审批。

**目标：** 创建可构建、可测试的代码与图片 Agent CLI。
**架构：** Provider 返回文本和工具调用，AgentLoop 调用统一注册表；工具通过 PermissionGate 请求 Ink 确认。
**技术栈：** Node 22、TS ESM、Ink 6、React 19、OpenAI 6、Zod 4、yargs 18、Vitest 3、pnpm。

```ts
interface ToolCall { id: string; name: string; arguments: string }
interface ChatReply { content: string; toolCalls: ToolCall[] }
interface ImageInput { prompt: string; model?: string; size?: string }
interface ModelProvider {
  chat(messages: ChatCompletionMessageParam[], tools: ChatCompletionTool[],
    onText: (text: string) => void, signal: AbortSignal): Promise<ChatReply>;
  generateImage(input: ImageInput, signal: AbortSignal): Promise<Buffer>;
}
interface PermissionRequest { title: string; detail: string }
type Confirm = (request: PermissionRequest, signal: AbortSignal) => Promise<boolean>;
interface ToolContext { workspace: string; signal: AbortSignal; confirm: Confirm; provider: ModelProvider }
interface AgentTool {
  name: string; description: string; schema: z.ZodType;
  execute(input: unknown, context: ToolContext): Promise<unknown>;
}
```
