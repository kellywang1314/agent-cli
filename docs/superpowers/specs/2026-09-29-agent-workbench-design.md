# Agent 可视化工作台

用户要求类似 Codex 的可视化界面，并要求继续实施。采用本地浏览器工作台，复用既有 Agent 核心；不需要云端应用资产或部署。

## 界面与交互

- 左侧浅灰会话栏：工作区、创建任务、会话切换、删除空闲会话。
- 中间白色聊天区：欢迎页、任务建议、Markdown 回答、工具进度、固定多行输入框、停止按钮。
- 右侧检查面板：工具执行记录、文件列表与只读内容、Git 未暂存差异。
- 文件写入、Shell、图片生成展示完整详情，用户逐次批准或拒绝；等待期间可中断。
- 图片使用已有 `/image` 命令生成，显示结果路径。界面不引入装饰图片。
- 中文界面，窄窗口折叠侧栏，明确连接和错误状态。

## 接入

Node HTTP 服务仅监听 127.0.0.1。每个会话持有独立 AgentLoop、PermissionGate 和 AbortController。
HTTP 接口创建/删除会话、提交任务、取消、确认、只读检查；SSE 首次发送完整快照，后续只发送发生变化的会话，并限制浏览器历史与工具详情体积。
浏览器只收到模型名称与工作区信息，不接收 AK 或网关鉴权地址。
启动生成随机会话访问令牌，通过 URL fragment 交给浏览器；所有 API 要求请求头令牌并检查 Host/Origin。
工具结果和流式输出沿用脱敏规则；完整内容与未结束流分别处理，避免误截断。`.env*`、依赖目录和 Git 元数据不允许模型或面板读取。审批使用唯一 ID，阻止过期操作。断线宽限 15 秒后中断任务，重连可恢复已有状态。
会话保存在本地服务内存，页面刷新可恢复，服务重启后清空；最多 20 个会话。

## 文件边界

新增 `src/web/` 服务与浏览器源码，保留 `src/main.tsx` 终端入口。
前端 React + React DOM，esbuild 打包到 `dist/web-assets`；不引入额外全栈框架。
默认 `pnpm dev` 启动图形界面并打开浏览器，`pnpm dev:cli` 启动原终端。

## 验证

使用本地假模型做 HTTP 集成验证：鉴权与来源拒绝、创建与隔离会话、流式状态、授权拒绝/允许/过期、取消、文件读取。
执行原有 59 项测试、类型检查、完整构建；浏览器检查布局、任务提交、文件面板和权限交互。
使用现有 AIDP 配置做一次只读聊天联调。图片计费调用不属于界面验收。
